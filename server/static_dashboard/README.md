# 중앙 서버 대시보드 (정적 프로토타입)

이 폴더는 **외부 중앙 서버 측에서 동작**하는 운영자/관리자용
**메인 모니터링 대시보드** 프로토타입입니다.

라즈베리파이 로컬 디버그 UI가 아닙니다.

## 목적

- 여러 대의 라즈베리파이 엣지 디바이스에서 올라오는 결과를 통합 표시
- 실시간 CCTV 상태 모니터링
- 오염도 점수 / 기기 수치 판독(OCR) / 화재 발화점 추적 / 이벤트 통합 조회
- 모델 버전, 서버 상태 점검

## 주요 섹션

- 실시간 CCTV 상태
- 오염도 현황 (미연동)
- 실시간 기기 수치 판독 (OCR)
- 실시간 발화점 추적 현황 (YOLOv8)
- 이벤트 기록
- 설정

## 포함되는 카드/테이블

- CCTV 목록 및 통계 카드 (서버 상태, 오프라인 기기 수)
- 장치별 오염도 점수
- 실시간 기기 수치 판독 (CCTV 화면 내 온습도계/시계 OCR 결과)
- 실시간 발화점 추적 현황 (화염 객체 이동 경로 및 위험도)
- 이벤트 기록 (명령/알림 내역)
- 우측 상단 현재 위치 날씨 검색 위젯 (Open-Meteo API 연동)

## 실행 방법

이 UI는 정적 HTML/CSS/JS 입니다. 별도의 빌드 단계가 필요 없습니다.

1. 백엔드 API 를 먼저 실행합니다 (레포 루트에서): uvicorn server.api.main:app --reload --port 8000
2. 2. 대시보드를 정적 서버로 띄웁니다:
cd server/static_dashboard
python3 -m http.server 8000

3. 브라우저에서 `http://localhost:8000` 접속.

`file://` 로 직접 열어도 화면은 보이지만, 브라우저 CORS 정책상 API
호출이 막힐 수 있으므로 정적 서버 사용을 권장합니다.

### API 주소 변경

기본 API 주소는 `http://localhost:9000` 입니다. 다른 호스트로 바꾸려면
`index.html` 의 `window.API_BASE` 값을 수정하거나, 스크립트 로드 전 선언하면 됩니다.

## 현재 상태 (라이브 연동 완료)

> **🎉 업데이트:** 정적 대시보드가 FastAPI 백엔드와 완벽하게 라이브 연동됩니다. 
> 특히 엣지 디바이스에서 전송하는 **YOLOv8 화재 감지 이벤트**와 **EasyOCR 수치 판독 이벤트**를 수신하여 화면에 실시간으로 렌더링합니다. (오염도 점수 부분만 추후 확장을 위해 미연동 상태로 남겨두었습니다.)

`script.js` 가 `COMMUNICATION_PROTOCOL.md` v0.1 의 GET 엔드포인트를 호출하며, 화재 및 OCR 데이터를 분류하여 출력합니다.

| 섹션 | 데이터 출처 | 상태 |
| --- | --- | --- |
| 실시간 CCTV 상태 (목록 + 통계) | `GET /api/devices` | ✅ 라이브 |
| 이벤트 기록 | 장치별 `GET /api/devices/{id}/events` 병합 | ✅ 라이브 |
| 설정 (모델 버전) | heartbeat 의 `inference.model_version` | ✅ 라이브 |
| 실시간 기기 수치 판독 (OCR) | `GET /api/devices/{id}/events` (type: `ocr_reading`) | ✅ 라이브 |
| 실시간 발화점 추적 현황 | `GET /api/devices/{id}/events` (type: `fire_tracking`) | ✅ 라이브 |
| 오염도 현황 | (프로토콜 미정의) | ⛔ 미연동 |

- 우상단 배너로 API 연결 상태(연결됨/오프라인)를 실시간으로 표시합니다.
- 서버가 꺼져 있으면 가짜 데이터를 보이지 않고 오류 메시지를 표시합니다.
- 단순 이벤트 나열에 그치지 않고, `ocr_reading`과 `fire_tracking` 이벤트를 자바스크립트(`script.js`) 단에서 필터링하여 각각의 전용 테이블과 시각적 알람(점멸 UI)으로 직관성 있게 분리하여 표현합니다.
- 대시보드 화면상에서 CCTV 테두리 알람을 강제로 끄는 **원격 제어 명령(POST)** 전송 기능이 구현되어 있습니다.
